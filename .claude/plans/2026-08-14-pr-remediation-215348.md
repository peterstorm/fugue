## Surviving critical findings (mandatory — both are the same defect)

### C1 = `silent-failure-hunter-1` + C2 = `silent-failure-hunter-5`
`InMemoryCheckpointer.saveNode`/`load` reject with a **raw untyped `Error`** when
`structuredClone` fails on non-cloneable stored state (function/symbol in
`NodeState.output`/meta), instead of returning `Err<FrameworkError>` as the
`Checkpointer` port contract (ADR-0080, FR-040) requires — the file backend maps
the same value class to typed `checkpoint-write-failed`.

All three refutation lenses (`reproduction`, `intent`, `blast-radius`) **upheld** both
findings; zero refuted criticals.

**Fix — `packages/framework/src/checkpoint/checkpointer.ts`:**
1. `saveNode`: wrap `detachStored(state)` — on failure return
   `err(checkpoint-write-failed)` with **truthful branding** (grammar-valid raw
   `nodeId` inhabits the branded field; invalid raw ids go to an additive
   `invalidNodeId` rendered via `safeDiagnosticRender`; `runId` is already branded
   by the port signature).
2. `load`: wrap both detach calls — on failure return
   `err(checkpoint-corrupt)` (stored state undetachable = stored-state corruption;
   mirrors the file backend's corrupt-on-read verdict). Also guard the injected
   `this.now()` TTL probe → typed `cache-error` instead of a raw rejection.
3. `setMeta`: **detach `meta` at write time** (snapshot parity with file/Redis,
   which serialize at write) — on failure return typed `cache-error`; guard
   `this.now()` the same way. This also fixes advisory A4 below.
4. Imports: `ID_PATTERN` (`../types/ids.js`), `safeErrorMessage`/`safeDiagnosticRender`
   (`../types/safe-error.js`), `frameworkError` (`../types/error-factories.js`).

**Tests (pin the contract):**
- `_checkpointer-suite.ts`: (i) **alias pins** — mutate caller state after
  `saveNode`, mutate caller meta after `setMeta`, mutate the object returned by
  `load`; assert stored/loaded values are unaffected (passes for file/Redis/in-memory);
  (ii) `load`-detach failure… (in-memory only, below).
- `redis-checkpointer.test.ts` (InMemoryCheckpointer block): `saveNode` with
  function-valued output → `result.ok === false` + `kind === "checkpoint-write-failed"`
  (never a rejection); invalid-raw-nodeId truthful-brand case; `setMeta` with
  uncloneable meta → typed `cache-error`; `load` with a function smuggled via
  `__testRawMetas` → typed `checkpoint-corrupt`.
